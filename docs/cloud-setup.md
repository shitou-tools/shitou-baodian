# 自行配置阿里云备份

本仓库不提供公共备份服务器，每个使用者部署自己的实例。

1. 新建私有 OSS Bucket，开启阻止公共访问，使用标准存储。记录自己的 Bucket 名和地域代码。
2. 在 RAM 中创建自定义策略，将 `cloud/ram-policy.json` 的全部 `your-backup-bucket` 替换为自己的 Bucket 名。策略仅允许列举、读写备份目录及删除 v1 快照。
3. 创建信任函数计算服务 `fc.aliyuncs.com` 的 RAM 角色，并关联这份策略。
4. 新建函数计算 FC 3.0 函数，选择 Python 3.10 或 3.12，入口 `index.handler`。将 `cloud/index.py` 打包为 ZIP（index.py 位于根目录）并上传。给函数选择刚创建的角色，允许访问 OSS 网络，超时可设置为 60 秒，最小实例数 0。
5. 在函数环境变量填写：

| 变量 | 值 |
| --- | --- |
| `OSS_BUCKET` | 自己的 Bucket 名 |
| `OSS_REGION` | Bucket 的地域代码，例如 `cn-hangzhou` |
| `BACKUP_TOKEN` | 自行生成的 32～256 位随机口令，只包含字母、数字、下划线或横线 |

可用插件“首次配置：生成并复制连接口令”生成口令，保存到自己的密码管理器，再粘贴到函数环境变量。不要将口令放进代码或 README。

6. 创建 HTTPS HTTP 触发器，仅允许 POST；函数代码自行验证 Bearer 口令。若使用此方案，HTTP 触发器的网关认证方式选择无需认证，代码中的口令验证必须保留。
7. 将函数的 HTTPS 地址填写到插件“云端备份”，填写相同口令，点击“验证并保存连接”，再点击“立即备份”。允许插件访问自己的服务域名。
8. 看到成功时间后，在自己的 OSS 中检查 `prompt-box-backups/v1/` 是否生成 JSON。下载并验证备份内容，再开启自动备份。

所有凭证均由你自行设置。函数通过所关联角色获得短期 OSS 凭证，插件不需要阿里云 AccessKey。换电脑后用同一地址和口令连接，手动选择云端历史进行合并恢复。

服务地址默认仅接受 `*.fcapp.run` 和 `*.fc.aliyuncs.com` HTTPS 域名。自定义域名或其他云服务需修改前端域名校验与 manifest 可选权限。

备份不会自动清理。删除仅作用于所选云端快照；没有版本控制时可能无法找回。云资源按自己的阿里云账户计费。
