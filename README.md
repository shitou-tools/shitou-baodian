# 石头宝典

> 石头宝典 Token烧出来的提示词

一个本地优先的 Chrome 提示词管理插件。受到白无常老师分享的启发，从头实现，并加入可选的阿里云自动备份。感谢白无常老师的分享。

## 功能

- 提示词分类、搜索、置顶、一键复制和使用备注。
- 自动保存草稿、回收站、本地 JSON 导出和合并恢复。
- 可选阿里云自动备份，独立历史页面，每页 10 份，支持下载、预览恢复和确认删除。
- 侧栏与完整管理页、右键保存选中文字、快捷键打开。

## 安装

1. 下载本仓库（Code → Download ZIP）并解压。
2. Chrome 116 或以上版本打开 `chrome://extensions`，开启开发者模式。
3. 点击“加载已解压的扩展程序”，选择 `extension` 目录。
4. 固定“石头宝典”到工具栏，点击打开侧栏。

更新时覆盖原目录后点击扩展卡片的刷新按钮；不要卸载。卸载会清除本机扩展数据，建议先导出备份。

## 云备份

不配置云服务也可以离线使用。公开版没有内置作者的服务地址、云账号、Bucket 或连接口令，也没有附带作者的提示词库。

阿里云部署见 [云备份配置](docs/cloud-setup.md)。每个使用者需要部署自己的服务，承担自己的云资源费用。连接口令应自行保管，不要提交到仓库。

跨电脑使用目前是：连接同一备份服务 → 查看云端历史 → 预览并合并恢复；不是实时双向同步。

也欢迎把项目交给 Agent，改成适合自己的云备份方式。相关入口：`extension/src/cloud.js`、`extension/src/cloud-ui.js`、`cloud/index.py`。更换云提供方时需同时调整域名校验、可选主机权限、服务接口和测试。

## 开发

前端无第三方运行依赖；云函数仅使用 Python 标准库。

```sh
node scripts/prepare.mjs
node scripts/check.mjs
npm test
python -m unittest discover -s tests -p "test_*.py"
node dev/server.mjs
python scripts/package_release.py
```

使用现代 Node.js（支持 `import.meta.dirname`）和 Python 3.10 以上版本。`dev/` 是隔离演示，不连接真实 OSS。`tests/fixtures` 是人工测试样例，不是用户资料。

## 隐私与限制

提示词默认存于本机 Chrome。只有用户配置连接并主动备份或开启自动备份后，才上传到自己填写的服务。导出的提示词 JSON 不含连接口令；口令保存在本机扩展存储中。没有统计埋点或第三方 AI 接口。

云端备份不是端到端加密：云存储账号持有者可读取备份，连接口令持有者可通过服务读取和删除备份。删除单份快照需确认，插件内不能撤销该云端删除；本地提示词不受影响。

当前数据容量约 9 MB，正文单条最多 100,000 字符，备注最多 5,000 字符。浏览器运行且联网时，每 5 分钟检查变更；关闭或休眠期间不能按时上传。
